# Archive transition

Mockups for the thread panel animating when the open thread is archived
(30 Oct). Before this the sidebar row slid off but the panel just flicked
to the next thread.

- `first-round/`: five directions (lift, slide, card underneath, into the
  archive, blur swap). Mike liked "into the archive", but there's no
  Archive view any more, just the folded Archived heading.
- `index.html`: three takes on flying into the Archived heading. Mike
  picked D2, Drop, which is what `ArchiveFlight` in the app does.

Open `index.html` to play them (keys 0 to 3, ⌘E replays, Slow-mo).
`filmstrip.html?v=D2` freezes four moments of one for the stills.
