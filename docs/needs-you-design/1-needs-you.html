1. A turn that needs you

The agent ends with end_turn({ needs: "you", asks }). The card under its last message lists each ask with a tick box: what to do, then where on a quieter line.

Ticking only marks it done for you. It never sends anything, because sending starts a turn that costs money.

An ask with a reply gets a chip ("done", "fix it"). The chip puts that reply in the composer for you to send.

The sidebar row shows the first open ask instead of the last line of the reply, so you can see what's wanted without opening the thread.
