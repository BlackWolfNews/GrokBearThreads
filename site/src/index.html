I kept wanting to change my agent app

{{icon cursor-click}}

Someone else's app

The agent apps I used were good, but each had a few things I couldn't change. Picking a project for every thread when it's nearly always misc, images that only half worked, and agents dying whenever the app quit or updated.

{{icon bandaids}}

With Threadbear

New threads just start in your usual folder, and images show up right in the thread. A little runner in the background owns the agents, so quitting the app never stops a turn. And when I want something new, I ask a thread to add it.

What it does

{{icon bandaids}}

Ask for a button and get one

Patches are small TypeScript files in your project's .threadbear/patches folder. They add buttons above the message box, panels beside the thread, and commands that run after each turn. Your agent can write one while you watch, and it shows up a few seconds later.

A few come built in, like the Convex dashboard for a folder with Convex in it, and a Simulator panel for an Xcode project.

{{mac mac-patches crop}}
{{icon device-mobile}}

Your threads on your phone

The iPhone app has your inbox and the latest messages in each thread. You can reply, approve a command or answer a question from the couch, and it sends you a notification when a thread needs you.

Every thread has its own link too, so you can open it in a browser or paste it to yourself.

{{icon key}}

Runs on the subscriptions you already pay for

Threadbear drives the official Claude Code and Codex command line tools, logged in as you, so it's your plan doing the work and nothing extra on top. Pick Claude or Codex, the model and how hard it thinks, per thread.

Got more than one account? The menu shows each login and how much it has left.

{{mac mac-accounts crop}}
{{icon lightning}}

Quick, even with lots of threads

It's a native Mac app written in SwiftUI and AppKit, so it opens fast and stays light. Threads that have gone quiet hibernate after half an hour, so their CLI isn't sitting there eating memory, and wake up right where they left off when you message them.

{{mac mac-diffs crop}}
{{icon database}}

Your own backend, on Convex

When you install Threadbear it makes a Convex deployment in your own Convex account, and that's what your phone and browser talk to. Thread titles, the latest messages and anything waiting on you go up there. Full transcripts, tool output and images stay on your Mac.

None of it runs on a server of mine, so I never see any of it.

How it works

  1. 1 {{icon git-fork}}

    Fork it and install

    Fork the repo, clone it and run the installer. It builds the Mac app and the runner, and sets up a Convex deployment that's yours.

  2. 2 {{icon terminal-window}}

    Use your Claude Code or Codex login

    If you already use either one in a terminal, that's it. Threadbear starts threads with the logins already on your Mac.

  3. 3 {{icon qr-code}}

    Pair your iPhone

    Scan the pairing code with the iPhone app and your threads show up on your phone.
